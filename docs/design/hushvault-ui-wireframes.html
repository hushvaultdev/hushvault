Mobile behavior

Organisation remains visible in the top bar, environment selection wraps, and each secret becomes a readable card with its value still masked.

Menu drawer

Menu exposes the same destinations as the desktop rail.

Touch actions

Actions have separate labels and comfortable tap targets.

Trust and security

Pre-release and unaudited status stays near the primary CTA. Security content explains server-held key custody and the self-hosting material's current limitations.

Available versus planned

Current capabilities, beta integrations, and planned hosted plans have separate labels. Pricing and “free” claims do not promise zero infrastructure cost.

Focused flows

Auth uses a single-column form. Onboarding uses three steps: project, first secret, and CLI, with visible progress and recovery states.

Other customer pages

Docs and Security use readable article layouts. FAQ, Pricing, Integrations, Members, Audit, and Billing reuse the light card and responsive spacing system.
